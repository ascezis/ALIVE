# Развёртывание

`Dockerfile` собирает веб-образ с FastAPI, ReportLab и готовым Mini App. `Caddyfile` маршрутизирует рабочий HTTPS-адрес к API. Процесс Telegram запускается отдельным контейнером с общим монтированием SQLite.

Адреса, переменные, проверка бота, выпуск и откат описаны в [руководстве по эксплуатации](../docs/operations.md).
